# SwiftTill POS Agent Database Portfolio

## MIT 8103: Advanced Database Systems

This repository contains my database portfolio for the SwiftTill POS Agent Management System. The project demonstrates how database concepts can be applied to manage POS agents, terminals, transactions, settlements, and support activities.

## Project Objectives

- Design a relational database with appropriate tables and relationships.
- Write SQL queries and analyse query performance.
- Demonstrate transaction management and concurrency control.
- Explore NoSQL data modelling and queries using MongoDB.
- Propose a distributed database architecture with replication, availability, and recovery strategies.

## Portfolio Contents

### Portfolio 1: Database Design and Modelling
Folder: `portfolio-1-database-design`

Covers database schema design, entity relationships, normalisation, constraints, and SQL table definitions.

### Portfolio 2: Query Optimisation
Folder: `portfolio-2-query-optimisation`

Covers SQL queries, execution plans, indexing, and query performance analysis.

### Portfolio 3: Transactions and Concurrency
Folder: `portfolio-3-transactions-concurrency`

Demonstrates transaction management, `COMMIT`, `ROLLBACK`, terminal updates, and concurrency concepts.

### Portfolio 4: NoSQL Database
Folder: `portfolio-4-nosql`

Explores a MongoDB document model and sample queries for SwiftTill agents and their POS terminals.

### Portfolio 5: Distributed Database and Cloud Systems
Folder: `portfolio-5-distributed-cloud`

Contains a proposed distributed database architecture, replication plan, and availability and recovery plan.
