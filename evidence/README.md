# SwiftTill Database Portfolio — Evidence

This folder contains screenshots and execution results supporting the SwiftTill POS Agent Management System database portfolio for MIT 8103: Advanced Database Systems.

## Portfolio 1: Database Design and Modelling

The evidence includes:

1. Database table creation and schema verification.
2. Primary keys, foreign keys, unique constraints, and status validation rules.
3. Evidence of an invalid agent status being rejected.
4. Successful insertion and retrieval of an agent record.
5. Successful retrieval of an agent and its assigned POS terminal using a JOIN query.

## Evidence Notes

The SQL tests were executed using browser-based PGlite (PostgreSQL in WebAssembly). These screenshots document the results from that environment.

Additional evidence will be added as Portfolios 2–5 are completed.
