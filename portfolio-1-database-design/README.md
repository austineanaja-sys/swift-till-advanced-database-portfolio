
Portfolio 1: Database Design

Project Overview
This portfolio documents the database design and implementation for the SwiftTill POS Agent Management System as part of MIT 8103: Advanced Database Systems.

Database Table: Agents
The `agents` table stores information about POS agents, including:
- Agent ID (primary key)
- First and last name
- Phone number and email address
- Location
- Registration date
- Account status

SQL Implementation
The `agents.sql` file contains SQL statements to:
1. Create the agents table.
2. Insert three fictional sample agent records.
3. Retrieve agent records using a SELECT query.

Testing
The SQL script was tested using an online PostgreSQL playground. The SELECT query returned three sample agent records.

Files
- `agents.sql` — SQL table creation, sample data insertion, and data retrieval.

Privacy Note
All agent names and contact details used in this academic demonstration are fictional.
